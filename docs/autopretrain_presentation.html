Progress

当前实验进展

MVP 3-Trial 验证：数据配比对 Reasoning 能力的影响

OLMo2-1B · 5000 steps · 8×H200 · 实时训练中

🥇 Reasoning-Heavy code 30% + math 30% 2.973
🥈 Llama-3 Baseline web 52% + math 26% 3.020

Key Finding: Reasoning-heavy 配比在相同 token 预算下 loss 更低，验证了"数据配比对推理能力有显著影响"的假设。

Roadmap

未来规划

Phase 0: 框架骨架 DONE

核心类型、Protocol 接口、状态机、诊断器、恢复器、监控器

Phase 1: MVP 验证 IN PROGRESS

Phase 2: 全自主搜索

MCGS 30-cycle 自动搜索 · 全参数空间（LR/batch/warmup）· Agent 7x24 运行

Phase 3: Scale Transfer

1B proxy 最优配方 → 3B 验证 → 7B+ 全量训练

Phase 4: 下游验证

LoRA SFT on NeMo Reasoning → Kaggle 提交 · MMLU/GSM8K/HumanEval 评测

Phase 5: 开源发布

独立项目发布 · 论文撰写 · 支持更多训练框架（NeMo, torchtune）
