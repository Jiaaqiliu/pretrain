Experiment in Progress

MVP validation: Does data mixture composition matter for reasoning?

OLMo2-1B · 5,000 steps · 8×H200 · Training Now

🥇 Reasoning-Heavy code 30% + math 30% 2.973
🥈 Llama-3 Baseline web 52% + math 26% 3.020
🥉 Uniform Control 25% each 3.025

Early Signal: The reasoning-heavy mixture achieves lower CE loss given the same token budget, providing initial evidence that data composition significantly impacts reasoning capability.
