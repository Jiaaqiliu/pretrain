## 关键发现

### 发现1: ψ 的增长集中在 stable phase, decay 贡献接近零

```
gaussian:
  warmup (0-500):     Δψ = +0.0177 (27%)
  stable (500-14500): Δψ = +0.0482 (73%)
  decay (14500-25000): Δψ = +0.0000 (0.07%)
```

**含义**: 序参数（低秩结构）的形成不是靠"退火"（降低 LR），而是靠"加热"（高 LR 驱动的梯度更新）。这与传统热力学中"缓慢冷却产生有序晶体"的类比**不一致**。

### 发现2: S 在 decay phase 上升 (所有 schedule)

所有三个 schedule 在 decay phase 都表现出 ΔS > 0（谱熵增加）。这意味着 LR 下降后，权重矩阵的奇异值分布反而变得更均匀（更无序）。

**可能解释**:
- LR 下降 → 梯度步长减小 → 无法维持之前高 LR 阶段强制形成的低秩结构
- 类似于"过冷液体"回弹到更稳定的无序态

### 发现3: Gaussian 是唯一 Δψ_decay > 0 的 schedule

虽然差异极小（+0.00005），gaussian decay 是三种 schedule 中唯一在退火阶段维持甚至微增 ψ 的。这**微弱支持**论文的"最小熵产生"假设，但信号太弱无法得出统计结论。

### 发现4: Phase 0.5 的 ψ_final < Phase 0 的 ψ_final

| Schedule | ψ_final (Phase 0) | ψ_final (Phase 0.5) |
|----------|-------------------|--------------------|
| gaussian | 0.0926 | 0.0792 |
| wsd_linear | 0.0950 | 0.0737 |
| wsd_exponential | 0.0940 | 0.0791 |

Phase 0 的 ψ 更高是因为数据循环 52 次使模型过拟合 → 权重矩阵发展出更强的低秩结构（"记忆"效应），而 Phase 0.5 是正常的语言建模学习。

## 可能的根本原因

### 为什么 190M 上 decay phase 不重要?

1. **模型容量饱和**: 190M 参数的"有效自由度"在 stable phase 已被充分利用，decay 时没有额外的结构可以发展

2. **数据-模型比不匹配**: 190M 模型在 14.5B tokens (stable phase 结束时) 可能已经 "chinchilla-optimal"，后续训练只是在 loss landscape 底部徘徊

3. **测量分辨率**: 使用 `get_local_tensor()` 计算的 SVD 是 FSDP 分片上的近似值，可能掩盖了全参数层面的微小变化

### 3B 会不同吗?

**理论上应该会**:
- 3B 有 16× 参数空间，decay phase 有更多"可重排"的结构
- 3B 的 chinchilla-optimal 是 ~60B tokens，在 50K steps (50B tokens) 时还没饱和
- 权重矩阵更大 (d=3328 vs d=768)，SVD 信号更稳定
